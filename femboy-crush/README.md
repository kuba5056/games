# Femboy Crush 💗

Match‑3 w stylu Candy Crush, ale zamiast cukierków – femboye.

## Jak uruchomić
Otwórz `index.html` w przeglądarce (albo `python3 -m http.server` w tym folderze).

## Obrazki
Wrzuć 5 zdjęć do folderu `img/` pod nazwami:

| plik | postać |
|---|---|
| `img/femboy1.png` | różowa bluza, serduszka |
| `img/femboy2.png` | goth, kręcone włosy |
| `img/femboy3.png` | kocie uszy, czarna koszulka |
| `img/femboy4.png` | psie uszy, biało‑czarny |
| `img/femboy5.png` | kocia bluza, różowo |

Format może być PNG/JPG – wystarczy zmienić nazwę w tablicy `TYPES` w `index.html`.
Bez obrazków gra działa na kolorowych kafelkach z emoji.

## Zasady
- Zamień dwa sąsiednie kafelki (klik‑klik albo przeciągnięcie), żeby ułożyć 3+ w rzędzie/kolumnie.
- 30 ruchów na poziom, cel punktowy rośnie z każdym poziomem.
- Kaskady dają mnożnik combo.
- Podpowiedź pokazuje możliwy ruch, Przetasuj kosztuje 5 ruchów.
