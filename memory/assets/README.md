# Zdjęcia do gry Memory

Wrzuć tutaj **8 zdjęć** o nazwach:

```
1.jpg  2.jpg  3.jpg  4.jpg  5.jpg  6.jpg  7.jpg  8.jpg
```

- Format: JPG (jeśli chcesz PNG, zmień `IMAGE_EXT` w `memory/index.html` na `png`).
- Najlepiej kwadratowe, ok. 300x300 px (większe też zadziałają — są przycinane do kwadratu).
- Jeśli któregoś zdjęcia zabraknie, gra pokaże w jego miejscu emoji.

Chcesz większą planszę? Zmień `PAIRS` w `memory/index.html` (np. 10 par = 20 kart)
i dodaj odpowiednio więcej zdjęć (`9.jpg`, `10.jpg`, ...).
